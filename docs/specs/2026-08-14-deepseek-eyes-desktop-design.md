# DeepSeek Eyes 桌面版 设计文档

- 日期：2026-08-14
- 状态：已批准，待实现

## 1. 目标

把现有的命令行/脚本代理 **DeepSeek Eyes** 升级为一个**完整的桌面应用程序（单个 EXE）**：

- 原生桌面窗口 + 系统托盘图标
- 全部操作可视化（日志、密钥、计费、启停、接入指南）
- 保持 OpenAI 兼容代理能力（任何支持 OpenAI 的 agent 都能调用）
- 一键打包成单个 `.exe`，双击即用

## 2. 技术选型

| 层 | 技术 | 理由 |
|---|---|---|
| 后端 | Python + FastAPI（现有） | 复用，改动最小 |
| 桌面窗口 | pywebview | 原生窗口内嵌 HTML/JS 界面，与现有 ECharts 面板无缝衔接 |
| 托盘 | pystray | 系统托盘图标 + 右键菜单 |
| 打包 | PyInstaller | 打成单个 exe |
| 数据 | SQLite（aiosqlite，现有） | 计费/用量数据 |
| 图表 | ECharts（已本地化） | 离线可用 |

## 3. 架构

单进程、单端口模型（2026-08-14 采纳用户建议，由双端口合并为单端口）。桌面壳是一个 Python 进程，跑一个 FastAPI 服务，端口 8000：

```
┌─────────────────────────────────────────────┐
│            DeepSeek Eyes 桌面进程             │
│                                             │
│  ┌──────────────┐   ┌────────────────────┐  │
│  │  pywebview    │   │   pystray 托盘      │  │
│  │  (原生窗口)    │   │  (右键菜单)         │  │
│  └──────┬───────┘   └─────────┬──────────┘  │
│         │ 加载 UI             │ 启停/退出     │
│  ┌──────▼─────────────────────▼──────────┐  │
│  │      FastAPI 服务（单端口 8000）        │  │
│  │                                        │  │
│  │  【常驻路由，不受启停影响】               │  │
│  │   - UI 页面 (/)                         │  │
│  │   - 日志查询 (/api/logs)                 │  │
│  │   - 密钥修改 (/api/config)               │  │
│  │   - 计费统计 (/api/stats)                │  │
│  │   - 服务启停 (/api/service)              │  │
│  │   - 接入指南 (/api/guide)                │  │
│  │                                        │  │
│  │  【代理路由，受服务开关控制】              │  │
│  │   - /v1/chat/completions                 │  │
│  │   - /v1/models /describe /ocr            │  │
│  │   - 图片→GLM→DeepSeek 转发               │  │
│  └────────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

**关键设计：软停止（soft-stop）**

- UI 路由（`/`、`/api/*`、`/static/*`）**常驻**，任何时候可访问——即使代理停了，用户仍能看历史账单和日志。
- 代理路由（`/v1/*`）受一个**全局开关** `service.running` 控制：开关关闭时，代理路由立即返回 `503 {"error": "service stopped"}`，agent 断连。
- 端口 8000 **始终监听**（UI 不能丢），"停止"是**逻辑停止**而非释放端口——这是单端口方案的自然语义。
- 托盘/UI 点"停止"后，agent 的请求会立刻得到 503，等同于断连。

## 4. 功能模块

### 4.1 日志系统（A+B+C 全要）

- **请求日志**：每次代理请求的进出（模型、耗时、token、含图、成败）
- **错误日志**：异常堆栈、上游失败、限流触发、GLM/MinerU 失败
- **系统日志**：启停、端口绑定、密钥加载、缓存清理
- **异步写入**：日志通过队列异步落盘，不阻塞请求主流程
- **实时滚动**：UI 通过 SSE（Server-Sent Events）或轮询批量刷新（500ms 攒一批），不逐条刷屏
- **落盘切片**：`logs/` 目录按天切片（`eyes-YYYY-MM-DD.log`），UI 可按日期回看、导出、清空

### 4.2 密钥管理

- 修改密钥走 UI 表单（控制服务的 `/api/config`）
- 显示：掩码 `sk-****b979`，点击"眼睛"临时显示明文，5 秒后自动隐藏
- 存储：明文 `.env`（用户选定方案 B）
- 修改后热生效（`config.reload()`）

### 4.3 计费与用量可视化

复用已完成的 `dashboard.html` 能力，迁移到控制服务 UI：
- 累计费用、token 总量、缓存命中率、图片/OCR 次数
- 每日 token 堆叠图、费用趋势、命中率趋势、按模型饼图、明细表
- 三口径（今天/本月/累计）+ 近 7/14/30 天 + 自动刷新
- 新增：实时请求"水龙头"视图（最近 N 条请求流）

### 4.4 服务启停（A2 语义）

- 托盘右键"开启/停止代理服务"
- UI 有醒目的开关按钮
- 停止 = 释放 8000 端口，agent 断连；但控制服务 8001 常驻，历史数据照看
- 发请求时若代理已停，UI 提示"服务未启动"

### 4.5 接入指南

- UI 内置"接入指南"页
- 动态显示 base_url（含实际端口）、代理 key、给各 agent（pi/Codex/dsh/reasonix 等）的配置示例
- 一键复制

### 4.6 头脑风暴补充项（全部纳入）

1. **开机自启 + 最小化到托盘**：托盘菜单"开机自启"开关（写注册表 HKCU\...\Run）；关闭窗口时最小化到托盘而非退出
2. **端口占用自动处理**：启动时探测 8000 是否被占，被占则自动换端口并在 UI 明确显示实际端口
3. **单实例锁**：进程互斥锁（socket 绑定固定端口 + pid 文件），第二次启动唤起已有窗口
4. **首次运行引导**：首次启动弹出配置向导（填 DeepSeek key → 智谱 key → 生成代理 key → 测试连接 → 完成）
5. **自动检查更新**：连 GitHub Release 检查新版本，托盘气泡提示（可开关，失败静默）
6. **实时请求水龙头**：计费页加最近请求实时列表
7. **异常熔断提醒**：连续 N 次请求失败时托盘气泡提醒（如 key 失效/余额耗尽）
8. **数据导出**：账单/token 统计导出 CSV

## 6. 数据流

```
Agent ──(OpenAI 格式)──▶ 代理服务 :8000 ──▶ 图片→GLM / 文档→MinerU ──▶ DeepSeek
                              │
                              └──▶ 写 SQLite（requests 表）+ 写日志队列 ──▶ 日志文件

用户 ──▶ 控制服务 :8001 ──▶ 读 SQLite（计费）+ 读日志文件（日志）+ 启停代理
                              │
                              └──▶ pywebview 窗口渲染
```

## 7. 错误处理

- 代理未启动时请求：返回明确提示，不静默失败
- 端口占用：自动换端口 + UI 明确展示
- 密钥失效/余额耗尽：熔断检测 + 托盘提醒
- 日志写入失败：降级为仅内存 + 控制台警告，不影响代理转发
- 单实例锁：二次启动唤起已有窗口

## 8. 测试策略

- 控制服务独立于代理服务，可单独起停测试
- 每个 API 端点用 curl 验证（models/stats/logs/config/service/guide）
- 代理启停循环测试（开→停→开，验证端口释放与恢复）
- 日志切片与实时推送验证
- 打包后 exe 在干净环境启动验证

## 9. 依赖清单（桌面版新增）
